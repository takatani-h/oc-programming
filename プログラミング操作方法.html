Pythonプログラミング操作方法／ミニカー・タイムアタック編

プログラミング言語Pythonで書かれたプログラムを変更して、ミニカーの動きを調整します。加速、ブレーキ、ハンドルの切れ方を自分で設定し、コースのゴールを目指します。

1．プログラムの立ち上げと基本操作

1）プログラムを開く

下のリンクURLをクリックして、ミニカー・タイムアタックのプログラムを開きます。

https://kitao.github.io/pyxel/web/code-maker/?gist=efd559a4e924b5070721bd5d25819f4c

プログラムを実行すると、コースとミニカーが画面に表示されます。

2）ミニカーを操作する

キーボードの矢印キーを使って、ミニカーを操作します。

キーミニカーの動き
上矢印キーアクセル
下矢印キーブレーキ
左矢印キー左に曲がる
右矢印キー右に曲がる
Rキースタート地点からやり直す

上矢印キーを押してミニカーを前進させ、左右の矢印キーで進む方向を変えます。

画面左上の「TIME」は、走り始めてからの時間です。ゴールすると、タイムの文字が黄色に変わり、計測が止まります。

コースから外れると「COURSE OUT!」と表示されます。Rキーを押すとスタート地点へ戻り、もう一度挑戦できます。

2．プログラムを変更する方法

プログラムでは、英単語の後ろにある数値を変えることで、ミニカーの動きを調整できます。

変更する数値は、次の3項目です。

TURN_SPEED = 0.8
ACCELERATION = 0.03
DECELERATION = 0.50

数値を変更した後は、プログラムをもう一度実行して、ミニカーの動きを確認します。

3．アクセルの効き方を変更する

「ACCELERATION」は、アクセルを押したときの加速の大きさを表します。

ACCELERATION = 0.03
  1. プログラムから「ACCELERATION」を探します。
  2. 「0.03」を別の数値に変更します。
  3. プログラムを実行します。
  4. 上矢印キーを押し、加速の違いを確認します。

数値を大きくすると、短い時間で速度が上がります。数値を小さくすると、ゆっくり加速します。

数値を大きくしすぎると、急に速度が上がり、カーブを曲がりにくくなります。コースを走りやすい値に調整します。

4．ブレーキの効き方を変更する

「DECELERATION」は、ブレーキを押したときに速度を下げる大きさを表します。

DECELERATION = 0.50
  1. プログラムから「DECELERATION」を探します。
  2. 「0.50」を別の数値に変更します。
  3. プログラムを実行します。
  4. ミニカーを走らせ、下矢印キーを押してブレーキの効き方を確認します。

数値を大きくすると、短い時間で速度が下がります。数値を小さくすると、ゆっくり減速します。

このミニカーは、ブレーキを押し続けてもバックしません。速度が0になると停止します。

5．ハンドルの切れ方を変更する

「TURN_SPEED」は、左右の矢印キーを押したときに向きが変わる大きさを表します。

TURN_SPEED = 0.8
  1. プログラムから「TURN_SPEED」を探します。
  2. 「0.8」を別の数値に変更します。
  3. プログラムを実行します。
  4. ミニカーを走らせ、左右の矢印キーを押して曲がり方を確認します。

数値を大きくすると、ハンドルが大きく切れ、急なカーブを曲がりやすくなります。数値を小さくすると、ミニカーの向きがゆっくり変わります。

数値を大きくしすぎると、ミニカーの向きを細かく調整することが難しくなります。

6．ミニカーの調整チャレンジ

アクセル、ブレーキ、ハンドルの切れ方を組み合わせて、コースを走りやすいミニカーに調整します。

調整するときは、一度に多くの数値を変えず、1項目ずつ変更すると、動きの違いが分かりやすくなります。

  1. ACCELERATIONを変更し、加速を確認します。
  2. DECELERATIONを変更し、ブレーキの効き方を確認します。
  3. TURN_SPEEDを変更し、カーブの曲がりやすさを確認します。
  4. コースを最後まで走れるように、数値を調整します。

7．タイムアタック

ミニカーの調整が終わったら、スタートからゴールまでのタイムに挑戦します。

  1. Rキーを押して、ミニカーをスタート地点へ戻します。
  2. 上矢印キーを押すと、タイムの計測が始まります。
  3. コースアウトしないように、ゴールを目指します。
  4. ゴール後に表示されたタイムを確認します。
  5. さらに速く走れるように数値を調整し、もう一度挑戦します。

速く走るためには、最高速度だけでなく、加速、ブレーキ、曲がりやすさのバランスが重要です。

8．完成

Pythonの数値を変更して、自分で調整したミニカーが完成しました。プログラムでは、数値や条件を少し変えるだけでも、画面の中のものの動きを変えることができます。

おまけ．このプログラムで使ったPython

変数

ACCELERATION = 0.03

「ACCELERATION」という名前に「0.03」という数値を入れています。このように、数値などのデータに名前を付けて保存するものを変数といいます。

条件分岐

if pyxel.btn(pyxel.KEY_UP):

「if」は、決められた条件が成り立つときだけ処理を行う命令です。このプログラムでは、上矢印キーが押されているかどうかを調べています。

数値の計算

car_speed = min(car_speed + ACCELERATION, 2)

現在の速度に「ACCELERATION」の値を加えて、ミニカーを加速させています。「min」を使うことで、速度が2を超えないようにしています。
